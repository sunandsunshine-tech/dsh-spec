# Agent Note: 技能规则留在加载它的所有者处

Status: implemented

[English](2026-11-23-skill-rules-stay-at-their-loaded-owner.md) | 中文

## Problem

技能入口与 reference 可能用不同措辞陈述同一条规则。这些副本会漂移，任务跨越路由与详细执行边界时，模型还可能遵循错误的副本。把所有规则都移出入口也不能解决问题：模型在判断任务是否需要详细内容之前，就可能被迫读取完整 reference。

技能集合同时要求独立安装。集中各技能的 defaults 或合并相邻技能会减少文件数量，却会耦合本不属于同一能力的安装、触发和运行前提。

## Decision

每条规则留在首次作出相关决定前必须加载的资源中：

- 入口保留范围、授权、停止条件、不可逆顺序、完成证据，以及选择相关路径所需的足够细节；
- 使用某个路径必然需要完整细节时，reference 拥有这些格式与过程；
- 调用脚本前本来就要选择机械选项时，脚本 `--help` 拥有这些选项；
- 项目指令拥有项目特定值与约定。

每个事实只有一个所属资源。其他资源可以陈述路由所需的局部后果，但不重复完整规则。

`pr-description` 在入口路由 AI Usage，把模型、声明块、评分与回读清单留给 `references/ai-usage.md`。`translate-docs` 的三条路径负责准入与产生内容，由一个完成段拥有写入、退役、检查与汇报。`agent-notes` 在入口保留生命周期判断、companion ladder、归档 readiness 与冻结安全，由两个约定拥有活跃与归档格式细节。`client-ui-ux` 把详细消费方追踪留给一个章节。`record-browser-gif` 陈述输出保留结果，由编码器与 publication reference 拥有各自机制。其余结构调整遵循同一所有权判据。

16 个技能保持独立。技能只能以带 availability 限定的可选示例提到另一技能。共享工具、不同产物、不同触发或不同运行前提都不构成合并技能的理由。

模型证据跟随[模型证据只证明它实际检验的行为](../testing/2026-11-23-model-evidence-binds-changed-behavior.zh.md)所描述的变化行为。纯结构变化使用受影响的行为场景，而不是所有历史场景。

## Alternatives considered

**合并相关技能。** 这会减少名称数量，却把无关触发、完成状态和运行前提合在一起，也让采用者无法只安装实际使用的能力。

**把所有详细规则移入 reference。** 入口会变短，但简单的路由与安全决定也需要先加载完整详细约定。

**把所有规则留在入口。** 入口会更自描述，但 reference、脚本与摘要副本会漂移，最大的入口也接近上下文预算。

**集中共享 defaults 段。** 维护者只需维护一份，但每个独立安装的技能都会依赖一个它未必携带的资源。

**每次措辞修改都重跑所有模型场景。** 这证明的范围超过修改本身，也让无关历史证据变成永久的同步负担。

## Consequences

- 入口陈述路由、安全与完成；reference 与脚本帮助拥有作出路由决定后才需要的细节。
- 技能单独安装、可选兄弟技能缺席时仍保持完整。
- 结构调整可以继续，同时不删除不同能力，也不合并独立安装。
- 变化行为选择有针对性的模型证据；未受影响场景仍作为其实际运行修订的证据。
- 仓库保留 16 个独立技能，以及每个带默认值入口中逐字相同的 `## Defaults` 约定。
