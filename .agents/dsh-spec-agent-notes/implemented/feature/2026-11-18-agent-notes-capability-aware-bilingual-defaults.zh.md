# Agent Note: Agent Notes 默认采用能力感知的双语伴随文件

Status: implemented

[English](2026-11-18-agent-notes-capability-aware-bilingual-defaults.md) | 中文

## 问题

Agent Notes 曾把翻译伴随文件视为可选，Translate Docs 也只允许项目常驻指令或用户显式请求授权新建配对。因此，已经启用翻译机制的项目若没有另一份项目声明，就无法为新笔记授权对侧文件。缺少翻译机制与翻译失败还会产生相同的无翻译结果。

## 决策

对于每份新笔记和每个首次进入归档的单元，Agent Notes 按以下顺序选择翻译伴随文件：

1. 当前请求中的显式选择。
2. 现有的持久项目覆盖。
3. 可用、已启用、且能为该单元解析出唯一目标语言的项目范围翻译机制。
4. 不选择翻译伴随文件，使笔记保持 English-only。

翻译机制由项目已配置翻译的证据启用，例如项目指令、术语数据或既有维护配对。仅安装翻译技能不会启用它，也不会使它可用。项目覆盖或请求可以选择不翻译、一个或多个目标、限定范围或排除，且这些选择都不要求创建或修改 `AGENTS.md`。若剩余多个目标而没有唯一选择，默认不选择翻译伴随文件，且不询问默认值。

该默认阶梯不会仅因技能发生变化而为活跃笔记添加翻译伴随文件，也绝不为已封印单元添加。既有活跃笔记首次进入归档时，其归档单元会在封印前选择并补齐翻译伴随文件。其他情况下，既有活跃笔记可以继续保持选择性翻译。

当默认阶梯选定一个配对时，翻译与一致性检查就是该单元的必需工作。翻译、术语或配对失败时，流程以未完成单元停止，并报告源文件、目标语言、失败步骤与可继续的下一步。该单元不能被重新标记为 English-only，新归档单元必须在 `archive --write` 封印它之前完成。

Translate Docs 接受拥有文档范围的工作流技能作为第三种通用授权来源。该授权点名源文件路径或 glob，要求唯一解析出的目标语言，不能扩展到兄弟文档或 `.agents/skills`，目标不明确时不授予默认配对。该规则不点名 Agent Notes，也不导入它的 API。

Agent Notes 拥有翻译选择，并为脚本声明完整单元，包括项目直接提供的非翻译伴随文件。项目的翻译机制拥有翻译文件名、记录与一致性。图示及其他非翻译伴随文件仍由项目声明，不受翻译阶梯影响。脚本仍由参数驱动，不读取项目指令。

[Agent Notes 锻造记录](../process/2026-10-27-forging-dsh-spec-agent-notes.zh.md)与 [Translate Docs 锻造记录](../process/2026-10-28-forging-dsh-spec-translate-docs.zh.md)继续拥有各自的机制。本笔记部分取代它们此前的 English-only 创建默认值与「仅用户或声明可授权」的边界。

## 曾考虑的替代方案

**采用固定的双语默认值。** 它能保证伴随文件存在，但缺少翻译机制的项目无法完成，English-only 项目也会被迫依赖一项它没有启用的能力。

**让 Translate Docs 成为 Agent Notes 的硬依赖。** 它能连接两条路径，但任一技能都会失去独立安装与完成路径。

**把一致性记录机制复制进 Agent Notes。** 它能让一个技能保持自包含，却会重复 Translate Docs 的记录格式与检查，并为同一配对制造两个所有者。

**让 Translate Docs 点名 Agent Notes 作为授权工作流。** 它能让当前用例更直白，却会把通用配对机制耦合到一个调用方，并要求每个等价工作流都修改 Translate Docs。

**把已安装的翻译技能视为已启用。** 它不要求项目数据，却会改变每个安装该技能的项目中的全部新笔记，包括从未启用翻译的项目。

**机制缺失或目标歧义时询问用户。** 它避免静默选择，但缺少项目指令是有效状态，共享默认值约定要求完成一项默认选择。

**只保留 English-only 作为创建默认值。** 它保持零迁移和项目中立，但已启用的项目仍需另写声明，之后新笔记才能使用翻译机制。

**翻译失败后回退到 English-only。** 它会产出一个文件，却掩盖已选单元尚未完成，还可能封印一个与其选定组成不一致的归档单元。

## 后果

- 没有可用翻译机制的项目继续生成不含翻译伴随文件的笔记，且无需修改 `AGENTS.md`。其他已声明伴随文件仍可使用。
- 只有一个已启用目标的项目默认获得英文笔记、目标语言对侧文件与一致性记录。
- 请求或持久覆盖仍控制 English-only、目标、范围与排除的选择。
- 活跃笔记在首次进入归档前保留原有组成。已封印历史绝不新增翻译伴随文件。
- 翻译失败成为一次显式交接，不再被表示为成功的 English-only 结果。
- 两个技能仍可独立安装，脚本没有新增命令或项目配置解析器。
- Translate Docs 的 description 点名授权范围，具体机制仍由正文拥有。Agent Notes 的 description 继续聚焦笔记生命周期触发。安装副本、仓库通知与配对决策记录随本次变更一起调整。
