# Agent Note: 模型证据只证明它实际检验的行为

Status: implemented

[English](2026-11-23-model-evidence-binds-changed-behavior.md) | 中文

## Problem

一次模型场景只证明它在运行时所用确切技能文本上的行为。若把每个历史场景都视为对当前完整技能的主张，一个无关措辞修改就会使整套证据失效。触发选择的输入比行为更窄：模型读取正文之前，技能目录只提供名称和 description。

要求每个历史运行匹配当前正文，也会掩盖真正的覆盖问题。触发场景检验选择，行为场景检验一个具名决定；其中一方通过或文件发生变化，都不会使另一方成为当前证据。

## Decision

触发证据绑定 `skills/<name>/SKILL.md#name-description`，其值来自 frontmatter 的名称和 description。正文修改不会使触发选择证据失效；名称或 description 修改后，相应触发语料必须重新运行。

行为证据记录完整安装技能哈希，用它标明该次运行准备并加载的技能字节，同时记录该次运行检验的场景，也就是行为。trace 是模型可控的评审上下文，不是执行证明；行为主张由评审者认证，哈希与运行都不适用于后续字节。

一次修改只使它所改变行为对应的场景失效。需要模型判断时，这些场景运行有针对性的模型评估；无关场景仍作为其记录行为的历史证据。仓库测试校验场景形状、输入、断言、保留产物、触发面和内部一致的修订记录，但不要求历史行为哈希等于当前完整技能。

集成场景记录它读取的每个兄弟技能修订。只有当兄弟技能中该集成所依赖的行为发生变化时，才使该集成场景失效。

当前的输入与技能清单同时绑定规范化后的可执行模式和内容。历史运行用已提交的证据清单校验其所记录哈希，不重写历史，也不依赖仅存在于分支历史中的 Git 对象；缺失的历史输入不会用当前字节重放。解析后的 profile 记录认证路由、浏览器／媒体可用性与沙箱模式。内联提供方凭据只留在限定到已知模型端点的宿主侧回环代理中；模型命名空间只收到占位值。输出替换使用持续到进程退出的内核咨询锁，崩溃时自动释放，不进行不安全的陈旧锁回收。

## Verification

`tests/skill-scenarios.test.ts` 区分触发证据与行为证据：触发清单使用 frontmatter 表面，行为 trace 与运行清单标识所用确切修订，当前输入与技能模式仍匹配，历史输入匹配其已提交清单，记录的技能哈希保持内部一致。`tests/skill-evals/README.md` 说明证据模型；相关证据 README 说明各次运行的范围。

## Alternatives considered

**要求每个历史场景绑定当前完整技能。** 这种检查容易实现，却把无关文字当成行为回归，并让一个行为变化触发全语料重跑。

**不记录技能哈希。** 这样可以避免当前性检查，却移除了把回答与模型实际读取文本关联起来的来源。

**让触发证据绑定完整正文。** 触发选择只读取目录中的名称和 description，因此这不会增加选择信息，却会让正文修改无谓地重跑触发探针。

**保留当前技能相等检查，只在文档里说明过度失效。** 门禁仍会要求无关重跑，也没有编码真实的证据范围。

**把文件哈希当作文件内每个行为的证明。** 哈希标识字节，不标识这些字节覆盖的行为。

## Consequences

- 触发证据跟随触发输入；行为证据跟随具名行为。
- 一次模型运行只对它记录的修订保持有效。
- 行为修改需要能够裁决该行为的最小代表性模型证据，而不是所有历史场景。
- 当前技能结构、语料完整性、触发面、运行输入和保留产物仍由确定性测试负责。
- 后续修改不能静默复用旧 trace 作为新措辞的证明；无关证据保留为历史，变化行为增加针对性运行。
