# Agent Note: 证据跟随变更主张

Status: implemented

[English](2026-11-25-evidence-follows-the-change-claim.md) | 中文

## 问题

单一的全仓测试仪式无法证明所有类型的主张。确定性测试无法判断自然语言指令；历史模型运行无法证明变更后的字节；如果缺少隔离起点，关于修改前后效果的主张就可能把不同的环境误认为改进。保留每份产物还可能使私有数据扩散得比该主张所需的范围更广。

## 决策

证据根据变更提出的主张来选择：

| 主张 | 所需证据 |
|---|---|
| 机械规则或结构 | 能证伪该规则的确定性测试。 |
| 自然语言模型行为 | 在技能与输入的边界上开展行为评估，并绑定该评估实际运行的场景、输入和已安装技能树。 |
| 触发选择 | 绑定到面向模型的名称和描述以及触发语料的证据。正文修改不会使其失效。 |
| 比较性收益主张 | 在相同场景提示词、fixture（测试前置数据）、能力、沙箱和截止时间下，设置候选组与未安装目标技能的基线组；目标技能的安装与使用指令是预期的处理差异。 |
| 保留的提示词、输出、日志或产物 | 对每个保留路径和文件进行 canary 扫描；转换或编码后的内容是否包含私有信息，仍由语义评审判定。 |

模型运行器会为每次成功的行为、比较或触发运行写入 `evidence.json`。行为证据的当前性由场景定义、场景提示词与渲染后的提示词、输入清单，以及承载模型的执行配置决定。完整的目标技能树和同级技能树是所用字节必需的来源信息，而不是当前性选择器。因此，完整技能树发生变化并不会隐含地使每个场景失效；评审人应按现有模型证据决策的要求，选出行为发生变化的场景对象。比较证据的当前性还由所声明的比较条件决定。触发模式只暂存目标技能、语料 agent 文件和所选查询 fixture，要求工作区只读且未发生变化，并要求出现预期的稳定选择标记；它还会绑定触发面以及规范语料身份，包括 fixture 路径、内容和可执行模式。当前性根据这些选择器计算，而不会存成一个可变的当前性标志。

无目标技能组只能用作比较性主张的基线。候选组记录包含目标技能的来源信息；基线组不记录目标技能来源信息。两组都会绑定各自所安装的任何同级技能的来源信息。对于基线组，运行器会省略目标技能的安装和目标使用指令。无目标技能的比较组需要 `--counterpart`，生产环境的正式收录路径会在发布新实验组前校验候选组与基线组的配对。在基线出现之前，候选组保持 `candidate-only`。已配对的基线会记录候选组的 `evidence.json` 哈希，正式收录时要求该哈希与实际保留的候选文件一致。如果目标技能组记录也带有对应证据运行（counterpart）哈希，校验会要求这条可选的逆向关联与实际保留的基线文件一致，但不要求形成循环配对。无目标技能的行为运行会在模型启动前被拦下。候选组与基线组必须在场景提示词、输入、模型配置、执行配置、截止时间、比较条件、同级技能来源信息和隐私范围上保持一致；它们的渲染后提示词只能因目标处理方式不同而不同。

一次成功运行必须恰好有一个 `turn.completed` 事件，并且它必须是 trace 的最终事件。如果终止事件缺失、重复、失败，或者它不是最终事件，运行就会在正式收录证据（promotion）前失败。`--deadline-ms` 限制沙箱启动、模型执行、工作区与响应收集，以及正式收录前的每个宿主侧检查点。超时会终止仍在运行的沙箱；同步宿主工作在下一个检查点失败。正式收录开始前超时会丢弃暂存的运行叶（staged leaf）；可恢复替换开始后越过截止时间，则不会回滚该替换。默认值为 30 分钟。

在读取任何 trace 或保留的元数据之前，运行器会以非阻塞且有界读取的方式打开该文件，不跟随链接，并要求它是普通文件。在正式收录前，它会扫描原始 stdout 和 stderr、不论扩展名的每个暂存文件，以及保留输出路径，查找配置好的隐私 canary。扫描会按有界块读取二进制文件，能发现跨块边界的匹配，并拦下链接和特殊文件；报告只包含 canary 集合，并且仅当某个表面本身不含该匹配内容时，才额外报告该表面的相对路径。输出路径和对应证据运行（counterpart）路径的预检失败会报告所需的相对路径形状，而不会回显传入的绝对路径。`evidence.json` 会哈希一个可移植的 canary 范围：记录稳定的集合／值对，而当前 home 路径只贡献集合身份，不贡献路径值。实际执行仍会扫描真实的当前 home 路径。对已保留证据的校验要求集合名称与场景对象所选出的完全一致，并要求稳定值一致，同时扫描调用方提供的实际当前 home 路径，但不会把该路径同创作时的路径或校验者当前的 home 做比较。例行测试会对仓库中已提交的证据树执行实际扫描。canary 是发现泄漏的绊线，不能替代语义隐私评审。

在 `evidence.json` 出现之前创建的运行，仍须接受现有的场景、输入和已记录技能检查。缺少带类型的元数据既不会降低也不会提升这些运行的状态。新规则不会重写此前的每一项审计。

现有的[模型证据绑定记录](2026-11-23-model-evidence-binds-changed-behavior.zh.md)负责受影响行为的失效判定和精确修订绑定。现有的 [pre-push 检查记录](../../implemented/process/2026-10-28-forging-dsh-spec-pre-push-checks.zh.md)负责根据出站 diff 选择命令。本决策负责主张类型、场景与输入当前性选择器、比较实验组、终止事件完成判定、通用保留运行校验和隐私 canary；它不替代上述任一负责方。

## 验证

`tests/evidence-policy.test.ts` 覆盖主张类型和比较类型、触发面与语料类型、无目标技能限制、受影响场景的当前性、来源信息分离、跨实验组提示词的精确重建、保留文件中的当前性与来源信息重建、保留树快照、可移植的记录隐私范围、不同当前 home 下的校验、实际当前 home 扫描、不会泄露路径的根目录与子目录检查错误、伪造的隐私范围、不跟随链接读取普通文件、trace 大小与特殊文件拦截、终止事件、整次运行检查点、路径与二进制 canary、跨块边界匹配，以及完整的已提交证据树。`tests/runner-safety.test.ts` 用真实运行器入口验证以下情形：trace 以零状态退出但缺少完成事件、运行超过截止时间、无目标技能的正式收录前防护、伪造的对应证据运行当前性与来源信息、对应证据运行（counterpart）兼容性、触发模式边界、预期和被拦下的选择标记、fixture 路径遍历与覆盖写入拦截、fixture 可执行模式的保持，以及模型输出中出现 canary；失败的运行不会留下已正式收录的证据。

模型评估仍是人工开发操作。`pnpm test` 只运行确定性策略控制和已提交证据，不调用模型。集成截止时间用例可能在 Codex 启动前就超时，因此它证明的是整次运行器的截止时间与正式收录前失败，而不是当时确有正在执行的模型；较低层级的可中断子进程控制用例证明了截止时间能终止一个已经启动的子进程。

## 备选方案

**每项变更都运行所有可用门禁。** 这容易说明，却把时间花在无法决定该主张的证据上，还可能让绿色测试套件看起来像行为证明。

**所有技能变更都使用模型评估。** 它能观察自然语言行为，却无法替代精确的结构、格式或命令约定断言。

**把匹配的聚合值当作隔离基线。** 它避免搭建环境，但不受控环境或事先预热的状态不能支撑因果收益主张。

**在每次运行中存储 `current: true`。** 存下来的结论会成为另一个可变事实来源。当前性仍是由所记录的选择器计算出的关系。

**在本次变更中改写每一个历史证据叶节点。** 迁移成本带不来任何证明，而未发生变化的场景会保留其现有审计状态。新运行会获得带类型的元数据，但不会仅因旧运行缺少该字段就给它们重新贴标签。

**把完整技能树相等当作行为当前性。** 技能树摘要能标识一次运行所暂存的字节，却无法标识究竟是哪个场景的行为发生了变化。完整技能树相等规则会重跑或拦下无关场景，并推翻现有模型证据决策。

## 后果

- 新运行中的主张类型和当前性选择器均可由机器读取。
- 触发描述变更会使触发证据失效，但不会使行为证据失效。技能发生修改后，需要由评审人选出受影响的场景对象，而不是重跑完整技能树。
- 触发选择运行与行为运行使用同一个隔离运行器、终止事件检查、隐私扫描和可恢复的正式收录路径。
- 比较运行可以让两个实验组使用同一个隔离运行器。无目标技能组必须在正式收录前具备一项通过校验的对应证据运行。
- 零退出但未完整结束的模型 trace 或保留的 canary 不能成为已发布证据；在正式收录开始前超时的运行也不能。
- canary 门禁能发现所有保留文件类型中的字面泄漏；压缩、转换或渲染后的数据仍需要语义隐私评审。
- 在场景或输入发生变化，或者有针对性的运行提供新元数据之前，现有证据会保留其原先的当前／历史状态。
- 替换式正式收录在进程崩溃后可恢复，但不是一个原子目录交换；下一次运行器调用会修复备份窗口。
