# Agent Note: 证据跟随变更主张

Status: proposed

[English](2026-11-25-evidence-follows-the-change-claim.md) | 中文

## Problem

单一的全仓测试仪式无法证明所有类型的主张。确定性测试无法判断自然语言指令，历史模型运行无法证明已变更字节，没有隔离起点时，修改前后比较可能把不同环境误当成改进。保留每份产物还可能让私有数据扩散到主张所需范围之外。

## Proposal

证据根据变更提出的主张来选择：

| 主张 | 所需证据 |
|---|---|
| 机械规则或结构 | 能推翻该规则的确定性测试。 |
| 自然语言模型行为 | 在技能和输入边界上的行为评估或等价证据。 |
| 正文变更后的当前行为 | 针对受影响行为的新证据；旧证据只保留为历史。 |
| 名称或 description 变更后的触发选择 | 重新运行正例与近失例触发集。 |
| 收益或 ROI 主张 | 可比的隔离基线，以及候选测量。 |
| 保留的提示词、输出、日志或产物 | 对每个保留项做隐私检查；否则收窄主张和保留范围。 |

变更描述点名主张及决定它的证据。昂贵的模型评估不必在 CI 中常规运行，但没有模型评估的变更要说明哪项确定性证据决定行为，或为什么不需要模型评估。

现有[模型证据绑定记录](../../implemented/testing/2026-11-23-model-evidence-binds-changed-behavior.zh.md)拥有“行为证据绑定其执行字节”的规则。本提案拥有在确定性测试、模型证据、基线和隐私检查之间进行更广选择的规则。

跟踪：#134。

## Alternatives considered

**每项变更都运行所有可用门禁。** 这容易说明，却把时间花在无法决定主张的证据上，还可能让绿色测试套件看起来像行为证明。

**所有技能变更都使用模型评估。** 它能观察自然语言行为，却无法替代对精确结构、格式或命令约定的断言。

**把匹配的聚合值当作隔离基线。** 它避免搭建环境，但不受控环境或事先预热的状态不能支撑因果收益主张。

## Acceptance criteria

- 每项变更主张映射到一个或多个能够推翻它的证据条目。
- 行为或输入变化会使该主张的旧证据失效；无关历史证据被明确标记为历史。
- ROI 主张记录基线、候选、条件，以及测量如何隔离所声称的影响。
- 隐私评审覆盖每份保留产物，或者变更陈述收窄后的主张与证据集。
- 确定性检查继续守住当前格式、链接和 corpus 完整性。

## Risks

- 模型评估仍是概率性的，并可能过拟合提示词；结论必须限制在已测试行为内。
- 严格的产物隐私规则可能减少可复用证据并增加评审工作。
- 把主张拆分到不同证据类型时，如果变更描述没有列出全部消费方，跨切面行为仍可能未被充分测试。
