# 目标模板

使用仓库内的 `dsh-spec-agent-experience` 技能编写目标提示词；本模板只给常用预填模板。

```text
你的Token预算为无上限。

目标:
<目标内容>

边界:
- 从 `<branch>` 开新 worktree。每轮开始前 fetch 并检查基线，有更新时 rebase；每轮工作结束 commit 并 push 当前分支。
- 长任务使用任务列表记录工作项和状态；完成、阻塞或放弃时更新，使上下文压缩后仍可恢复。
- 不参考其他会话内容。
- 授权删除工作产生的临时过程文件和内容。
- 评审反馈问题成立的从根因修复并在目标范围内排查同类问题，不成立的以技术理由说明；同一问题重复出现时先回到根因，不以表面修补换取通过。
- 需要人工授权、但不影响完成条件的操作：不执行，也不因此阻塞当前工作；在请求人工审查时一并提出授权申请。
- <目标特有边界>

完成条件:
- <目标特定完成条件>
- 独立干净评审通过：评审者未参与实现、使用干净上下文。
- 人工审查通过。

人工介入条件:
- 除人工审查外的其他完成条件全部满足：将目标置为 blocked，请求人工审查。
- <目标特定的人工介入条件>
```
