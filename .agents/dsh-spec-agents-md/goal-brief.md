# 目标模板

目标由 agent 生成时，使用仓库内的 `dsh-spec-agent-experience` 技能组织上下文；本模板只给字段。

```text
Token 预算：无上限。

目标:
<目标内容>

工作要求:
- 从 `<branch>` 开新 worktree。每轮开始前 fetch 并检查基线，有更新时 rebase；每轮工作结束 commit 并 push 当前分支。禁止发布和创建 PR。
- 长任务使用任务列表记录工作项和状态；完成、阻塞或放弃时更新，使上下文压缩后仍可恢复。
- 不参考其他会话内容。
- <目标特有要求>

完成条件:
- <目标特定完成条件>
- 人工审查通过。

人工介入条件:
- 除人工审查外的其他完成条件全部满足：将目标置为 blocked，请求人工审查。
- <目标特定的人工介入条件>
```
