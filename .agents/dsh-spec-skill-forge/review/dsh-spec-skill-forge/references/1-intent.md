# 1. 意图识别

从请求、采用环境和采用者的声明位置确定：

- 名称、目标、边界和交付物。
- 模式。
- 交付语言、审查语言和附加触发语言。
- 锻造目录、最终落地位置和记录位置。
- 采用者声明位置给出的锻造设置。

模式：新建从想法或上游提炼。迭代读取当前技能和既有决策记录，记录不存在时按新建处理并记录。

名称最多 64 个字符，仅小写字母、数字和连字符。连字符不重复，名称与目录一致，不以连字符开头或结尾。确定问题、需求、期望效果和用途，不判断是否值得做或任务本质。

**完成**：目标、边界、交付物、模式、落地位置、语言、锻造目录和记录位置明确。

**检查**：另一个执行者能从请求和记录复述同样的目标与边界，并且没有未知项控制主要设计。

**失败**：补齐可撤销的默认值。仍无法确定时用裁定并记录。
