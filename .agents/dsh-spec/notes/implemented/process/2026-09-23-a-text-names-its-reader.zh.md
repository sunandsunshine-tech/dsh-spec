# Agent Note: 文本先定读者

Status: implemented

[English](2026-09-23-a-text-names-its-reader.md) | 中文

## 问题

「文本写给了错的人」这个事故,[扫描范围、内联理由与包 README](2026-09-18-scan-scope-and-the-package-readme.zh.md)已经记过一次:包 README 是在向维护者解释自己,而不是向安装它的人,那句写给维护者的话被删掉了。那次事故留在规范目录里的规则是「写之前先点名这页给谁看」——它只说该挑哪个读者,从没说挑这件事发生在什么时候,于是它当初要治的失败,对下一篇文本依然敞着门。

读者不是写着写着挑出来的,它由「这篇文本是什么、谁会收到它」决定,而这件事在第一句话之前就定了。本技能集合自己的正文是英文,因为读它的是 agent;README 由安装这个东西的人读;决策记录由下一个维护它的人读;PR 说明由评审它的人读。在这些都定下之前就动笔的文本,写给的其实是当时在场的人——提出这件事的维护者、正在看 diff 的评审者、作者将来的自己。征兆就是有一句话在向它的读者提问:问题是对着能回答的人说的,而一篇写完的文本,它的读者答不了。

## 决策

一篇文本的读者,在它措辞之前就定了。它是「这篇文本是什么、谁会收到它」的属性,在第一句话被挑出来之前,就已经定下了语域、前提和长度;所以一句写给当时在场者的句子,就是写给错的人的句子,要重写,不是删短。

文本陈述它的读者要照做的东西,它不提问。对着读者的一个问题,是一场没发生过的互动:文本是在作者不在场时被读的,它的读者答不了。读者在场、而且确实会回答的地方,提问才是对的形式:`attended` 下等维护者答复的那一步初始化流程、把决定交还给提问者的回复、以及动手之前请用户确认的那句界面文字。分别在于谁答得了,不在于标点,所以互动可以提问,记录和页面不能。

这条规则有三个落点,每个面向一个读者:

- `prose.reader` 把它带进规范目录,让采用这套模式的项目随整套继承。
- `AGENTS.md` 把它作为常备令载着,与和它同一前提的语言习惯规则并列。
- 本篇承载理由——目录里那一行没有地方放它。

两条边界让它不外扩。它不决定一篇文本用哪种语言写:那是 `prose.idiom` 的地盘,而它那句「一对文本按契约各有两侧」就是本规则用在另一个属性上。它也不决定某一份具体文档的读者是谁;那由每份文档自己的契约定,本规则只说:这个选择排在前面。

## 曾考虑的替代方案

- **让读者在写作过程中自然定下来。** 这正是那次事故的成因,而且它读起来像自由:作者在最后一笔之前,对每个读者都还留着门。它落选,是因为语域、前提和长度本来就是第一行那个选择的后果,所以读者是被默认定下的——由当时在场的人定——而写给错的人的文本,完整却无用。
- **把所有文本里的问句一律删掉。** 检查会变得机械,一道门禁就能数 `?`。它落选,是因为一句请用户确认动作的界面文字正在干它的活:读者在场,答复在动作之前到达,措辞就是机制本身,而不是没写完的问句。
- **只放进 `AGENTS.md`。** 一个落点,在这里干活的 agent 每次会话都碰得到。它落选,是因为「一篇文本写给不止一个读者」这件事对任何项目都成立,采用者必须从目录继承它,而本仓库故意不应用自己的目录。
- **把读者做成每份文档都申报的字段。** 一个 frontmatter 键或第一个标题,能让这个选择可见、可检查。它落选,是因为读者本来就由文档的契约推出——本技能集合的正文是英文,因为加载它的是 agent;一对文本按语言契约各有两侧——把一个已经定下的事实再抄一份,正是「一个事实一个落点」要防的漂移。
- **把规则留在目录里,理由交给 README 那篇笔记。** 不新增笔记,source 路径本来也解析得到。它落选,是因为那篇记的是同一次初始化运行里的四个决定,读者顺着 source 去查「文本为什么要先认读者」,读到的是一个扫描的修复史。

## 后果

**换来了什么。** 读者从「写着写着养成的习惯」变回「排在文本之前的决定」,而这个失败有了作者自己看得见的征兆:一句向读者提问的句子,要么是一场没发生过的互动,要么是这篇文本还没做出的决定。共享同一前提的两条散文规则现在读起来是一对——文本是什么,在这里定它的读者,在那里定它的语言——而不是一条顺带提了另一条。

**代价是什么。** 在写第一行之前点名读者,要多花一句话;契约本就定下它时,这句话是在说显而易见的事。读者不止一个的文本必须挑一个:技能文件由 agent 加载、由维护者评审,第二个读者的需要会变成第二篇文本——一份 PR 说明、一个 README、一篇笔记——而不是把第一篇写得更长。

**留给读者什么。** 没有东西在守它,也没法守:目录那一条以一句自检问句结尾,而不是一道门禁,所以检查在写的人手上,一篇向读者提问的文本会通过本集合现有的每一道检查。这条规则也没有点名任何一份具体文档的读者;契约留着这个空缺的文档,仍然要由它的所有者去定。
