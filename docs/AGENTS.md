# AGENTS.md

Standing orders for `docs/`. The folder is otherwise unmanaged: nothing creates it, nothing checks it, and a document here declares its own pairing by having a `.zh.md` counterpart beside it or not.

## The terminology table

- `terminology.md` binds both sides of every bilingual pair, because each row fixes a word both sides write. Adding, changing, or removing a row is therefore the maintainer's decision: it is asked for in the conversation and never inferred by whoever is editing. A working agent proposes a row; it does not add one.
- The table is maintained in English with its Chinese and first-occurrence columns standing in for the translation, so it has no `.zh.md` counterpart and declares no pair. Nothing pairs it, and the pairing gate leaves it alone.
