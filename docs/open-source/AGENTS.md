# AGENTS.md

Standing orders for `docs/open-source/`.

- **`example-plan.md` and `example-answers.md` are the record of one planning, kept as written.** They apply this folder's decision form to this repository, and their rows state what was decided then — including a five-section pull-request description, which a later decision moved to four sections. A row a later decision has superseded is history rather than a defect: it is not corrected here, and it is not reported as stale.
- **The live rules and decisions live in the `dsh-spec-agent-notes` skill and the tree it maintains.** The records under `.agents/dsh-spec-agent-notes/` state what was decided then; this folder is not a second copy of the standing orders.
