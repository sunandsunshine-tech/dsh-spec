# AGENTS.md

Standing orders for `docs/releases/`.

- **A release note is the record of the revision it published, kept as written.** The versions, counts, section lists and file names in it describe that release rather than the repository now, and a later change that moves a rule, a norm or a file does not update them.
- **The live facts have other homes.** `norms list` reports the catalog's size, the rules themselves are on `main`, and `.agents/dsh-spec/notes/` carries why a decision changed. A line here that a later revision superseded is history rather than a defect, and is not reported as one.
