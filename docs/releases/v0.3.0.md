<h3 id="en-v0.3.0">Open source: the guide ships, the baseline moves to rc.2, the checks run in CI</h3>

This release lays the base the repository needs to be public. Nine skills and no runtime dependency, unchanged.

### New Features

- The open-source guide goes public ([#33](https://github.com/sunandsunshine-tech/dsh-spec/pull/33)) by @DreamStar92
- Pull-request checks, main verification, and the vendored dependency submission ([#39](https://github.com/sunandsunshine-tech/dsh-spec/pull/39)) by @DreamStar92

### Improvements

- The pull-request description rules move from the template to the note, and the norm becomes self-contained ([#36](https://github.com/sunandsunshine-tech/dsh-spec/pull/36)) by @DreamStar92
- The paired-record semantics are re-ported from dsh rc.2 ([#38](https://github.com/sunandsunshine-tech/dsh-spec/pull/38)) by @DreamStar92
- The note, the norm and the standing order each gain a description-writing rule ([#51](https://github.com/sunandsunshine-tech/dsh-spec/pull/51)) by @DreamStar92

### Bug Fixes

- The archive gate matches dsh, and a class directory carries a marker ([#41](https://github.com/sunandsunshine-tech/dsh-spec/pull/41)) by @DreamStar92
- The dependency submission carries the `scanned` field the endpoint requires ([#47](https://github.com/sunandsunshine-tech/dsh-spec/pull/47)) by @DreamStar92
- The dependency submission names each package by its purl rather than a registry page ([#48](https://github.com/sunandsunshine-tech/dsh-spec/pull/48)) by @DreamStar92

### Chores

- The baseline follows to `dsh-v0.1.7-rc.2`, with templates and policy pages ([#37](https://github.com/sunandsunshine-tech/dsh-spec/pull/37)) by @DreamStar92
- `actions/checkout` and `actions/setup-node` move to v7 ([#50](https://github.com/sunandsunshine-tech/dsh-spec/pull/50)) by @DreamStar92
- The template drops its `Verification` section, and a description carries four ([#46](https://github.com/sunandsunshine-tech/dsh-spec/pull/46)) by @DreamStar92
- The email in the whole history is rewritten to a GitHub noreply address ([3d4d775](https://github.com/sunandsunshine-tech/dsh-spec/commit/3d4d775)) by @DreamStar92 — every SHA changed with it
