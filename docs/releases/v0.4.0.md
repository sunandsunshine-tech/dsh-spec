<h3 id="en-v0.4.0">Ten skills, a renamed norm, and hardened copy and CI gates</h3>

This release completes the set with the team workflow as its tenth skill, adds one gate over the installed copy and a stronger baseline step in CI, and renames the ownership norm id; the migration cost sits in Chores below. There is still no runtime dependency.

### New Features

- A tenth skill: the agent team workflow ([#54](https://github.com/sunandsunshine-tech/dsh-spec/pull/54)) by @DreamStar92
- The norms file becomes generated, and a hand-edited block refuses to be overwritten ([#53](https://github.com/sunandsunshine-tech/dsh-spec/pull/53)) by @DreamStar92
- An installed-copy consistency gate, with a fixed resolution for copy conflicts ([#61](https://github.com/sunandsunshine-tech/dsh-spec/pull/61)) by @DreamStar92
- Member naming and split affinity join the skill ([#58](https://github.com/sunandsunshine-tech/dsh-spec/pull/58)) by @DreamStar92

### Bug Fixes

- The baseline step fetches every revision in one pass and asserts each one ([#59](https://github.com/sunandsunshine-tech/dsh-spec/pull/59)) by @DreamStar92

### Chores

- The ownership norm id is renamed `owner.one-home` → `owner.ssot` ([#60](https://github.com/sunandsunshine-tech/dsh-spec/pull/60)) by @DreamStar92 — an adopted project's next `norms update` reports the old id as removed and prunes it, and `norms install --group owner` reapplies it
- The repository baseline follows to `dsh-v0.2.0-rc.2` ([#56](https://github.com/sunandsunshine-tech/dsh-spec/pull/56)) by @DreamStar92
- Paired-record command comments point at the installed entry point ([#57](https://github.com/sunandsunshine-tech/dsh-spec/pull/57)) by @DreamStar92
- The planning document marks its last three stages complete ([#52](https://github.com/sunandsunshine-tech/dsh-spec/pull/52)) by @DreamStar92
