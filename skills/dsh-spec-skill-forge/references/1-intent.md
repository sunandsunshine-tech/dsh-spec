# 1. Intent recognition


Determine from the request, adoption environment and adopter's declaration:

- Name, goal, boundary and deliverable.
- Mode.
- Delivery, review and additional trigger languages.
- Forge directory, final landing location and record location.
- Forge settings from the adopter's declaration.

Modes: create distills from an idea or upstream source. Iterate reads the current skill and existing decision records, treats a missing record as create, and records that.

The name has at most 64 characters and uses only lowercase letters, digits and hyphens. Hyphens do not repeat, the name matches the directory, and it does not start or end with a hyphen. Determine the problem, needs, expected effect and use. Do not judge whether the work is worth doing or what the task is essentially about.

**Complete**: goal, boundary, deliverable, mode, landing location, languages, forge directory and record location are clear.

**Check**: another executor can restate the same goal and boundary from the request and record, and no unknown controls the main design.

**Failure**: fill reversible defaults. When still undetermined, use a ruling and record it.
