# Agent Note: 可恢复的导出

Status: proposed

[English](2026-11-20-resumable-export.md) | 中文

## Problem

长时间导出在进程停止时会丢失全部进度。用户需要能够恢复导出，而不必重做已经保存的工作。

## Proposal

持久化导出检查点，并在重启后恢复它们。取消正在进行的导出时，必须删除临时输出，并保持上次保存的状态不变。

跟踪：[Issue #140，跟踪器条目“可恢复的导出”](../../../../issue.md#tracker-item-resumable-export)。

## Alternatives considered

**每次导出都从头开始。** 这样可以避免保存检查点状态，但重复工作会随导出规模增长，而且一次短暂中断就会丢弃已经成功生成的输出。

## Acceptance criteria

- 重启后，已保存的导出会从存储的检查点继续。
- 取消正在进行的导出会删除临时输出，并保持持久化状态不变。

## Risks

检查点写入可能与并发的恢复尝试发生争用；此外，进程失去对临时存储的访问后，取消清理可能失败。
