# Project UI rules

- The design system owns color, spacing, type, radius, icons, and supported themes.
- Every user-visible browser UI behavior change carries one continuous browser recording from one isolated run by default.
- A project change may declare labeled screenshots as its evidence override; screenshots must cover the affected consumers and states under comparable conditions.
- Use the shared button for primary, secondary, and destructive actions.
- The supported narrow viewport is 390 CSS pixels.
