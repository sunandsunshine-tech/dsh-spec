# Non-counting references

These forms do not count as visible same-project issue references:

<!-- Resolves Issue #17. Refs Issue #18. -->

```markdown
Resolves Issue #17. Refs Issue #18.
```

Inline `Resolves Issue #17` and `Refs Issue #18` are also non-counting.

- Cross-project: <https://github.com/example/other-project/issues/17>
- Cross-project: <https://github.com/example/another-project/issues/18>
