# Code-review trigger evidence

Eight isolated selection probes bind the current `dsh-spec-code-review` name and
description. Four proposed-change review requests select the skill. Four
adjacent requests for implementation, pre-push check selection, failure-contract
design, and visual-only review select `none`.

`trigger-matrix.tsv` records the expected and observed selection for each query.
Each query directory retains its own query binding, trace, stderr, final response
and pass status.
